## How To Connect & Push

1. Connect to the control hub's network.
2. Run `connectw.bat` (Windows) or `connectw.sh` (Linux)
3. Run `pushw.bat` (Windows) or `pushw.bat` (Linux)
4. Done

## How to use the code

Note: Ensure that the driverhub you're using has `adb` enabled if you're doing
this wirelessly.

1. Connect to the robot either wirelessly using the `connectw` script or via USB
   *(If you're doing this via USB, skip this)*
2. Run the `trybuild` script to test if it works *(Skip this if you're in a hurry)*
3. Run the `build` script to install the build onto the robot.
