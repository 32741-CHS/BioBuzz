## Integrating Pedro Pathing with our Code

1. Go to https://visualizer.pedropathing.com/ to create a path.
2. Export it as Java code and select "Class Only" in the dropdown
3. Place this path class code inside the pedro_path_paths file, renaming the class (and also the
   file) to a name that represents the path e.g. DriveInCiclesPathObj (Place PathObj at the end of
   the name)
4. Create a copy of the PedroPathOpModeTemplate, rename it to the new name, follow the comments
5. DONE!
